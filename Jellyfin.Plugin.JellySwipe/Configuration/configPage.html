JellySwipe

Open JellySwipe

Swipe through your library with friends, Tinder-style. Open it at /JellySwipe/ on this server.

Guests join a lobby with the 4-digit code or QR code. Only signed-in users can host games.
Anyone who opens JellySwipe can create games without a Jellyfin login. They use the libraries, watch state and devices of the user below. Signed-in users always host as themselves.
Requires the File Transformation plugin. Takes effect after a browser reload.
Hosts choose between all titles and a random selection. This caps both, e.g. for very large libraries on slow phones.
